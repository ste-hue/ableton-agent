# Chordarium 0.3.0 — superseded delivery model

The 0.3.0 notarized installer required activation and was uploaded to Lemon Squeezy.
It was verified by full download and SHA-256 on 2026-09-12. See the source
repository's docs/NOTARIZATION-HANDOFF.md for immutable signing/build evidence.

Stefano subsequently clarified the product model: the free demo exists only at
chordarium.com; the native installer is delivered only after payment. The latest
confirmation retains first activation with a license key in a dedicated dialog.
The intervening proposal to remove activation is superseded.

The public-download-plus-license-activation proposal in the earlier version of
this document was rejected and was never deployed. No public GitHub release
or binary asset was published. It must not be used as a current launch instruction.
The replacement is 0.3.1; see chordarium-0.3.1.md.
