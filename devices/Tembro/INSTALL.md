# Install Tembro V0 on macOS

1. Quit Ableton Live.
2. Copy the complete `Tembro` folder into:

   `~/Music/Ableton/User Library/Presets/MIDI Effects/Max MIDI Effect/`

   Keep `Tembro.amxd` and every `.js` file together in that folder.
3. Install and select the pinned `Ableton_Live_MCP` Remote Script by following
   the repository setup guide.
4. Reopen Live, choose **User Library → Presets → MIDI Effects → Max MIDI
   Effect → Tembro**, and drop `Tembro.amxd` on a MIDI track.
5. Enter the purchase email and Lemon Squeezy license key once. The device
   stores only the resulting session and license instance identifiers locally.

For the development smoke test, follow `docs/tembro-v0-run.md` instead of
activating a production license.
